# 🤖 Chatbot com Java, Quarkus e LangChain4j

Projeto de desenvolvimento de um chatbot utilizando **Java**, **Quarkus** e **LangChain4j**, explorando integração com modelos de Inteligência Artificial Generativa (LLMs), criação de agentes conversacionais e construção de APIs modernas.

O objetivo deste projeto é estudar e aplicar conceitos de **IA Generativa**, **engenharia de prompts**, **integração com LLMs** e desenvolvimento backend utilizando um framework Java moderno e performático.

---

## 🚀 Tecnologias utilizadas

- ☕ Java 21+
- ⚡ Quarkus
- 🧠 LangChain4j
- 🤖 Integração com LLMs (OpenAI / Ollama / outros modelos)
- 🌐 REST API
- 📦 Maven
- 🐳 Docker (opcional)

---

## 📌 Sobre o projeto

Este projeto implementa um chatbot capaz de receber mensagens de usuários e gerar respostas utilizando modelos de linguagem.

A aplicação utiliza o **LangChain4j** como camada de abstração para facilitar:

- Comunicação com modelos de IA
- Gerenciamento de prompts
- Criação de assistentes virtuais
- Histórico de conversas
- Integração com ferramentas externas (Tools)
- Futuramente: RAG (Retrieval Augmented Generation)
